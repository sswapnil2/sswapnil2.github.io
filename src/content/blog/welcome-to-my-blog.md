Hello and welcome to my new blog!

I've rebuilt my personal website from the ground up using [Astro](https://astro.build), a modern static site generator that makes it easy to write content in Markdown while enjoying a great developer experience.

## What to Expect

I'll be writing about:

- **Software Development**: Tips, tutorials, and insights from my work as a developer
- **Technology**: Reviews and thoughts on new tools, frameworks, and technologies
- **Personal Projects**: Updates on side projects I'm working on

## Why I Rebuilt My Site

I wanted a simpler, faster website that focuses on content. Astro provides:

1. Lightning-fast page loads with minimal JavaScript
2. Native Markdown support for writing blog posts
3. A clean, maintainable codebase

## Writing Posts

Adding a new blog post is as simple as creating a Markdown file in the `src/content/blog/` directory with some frontmatter:

```markdown
---
title: 'Your Post Title'
description: 'A brief description of your post'
date: 2026-01-17
tags: ['tag1', 'tag2']
---

Your content here...
```

Thanks for visiting, and I hope you find something useful here!
